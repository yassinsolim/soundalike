Blinded pacing & tone study

This research-only study compares two anonymous whole-track ranking methods using approximately 20-second excerpts centered on each track's strongest repeated section. Repetition is a recurrence heuristic, not a verified chorus classifier.

Seeds prioritize anonymous method disagreement without using listener ratings. The two list labels are randomized independently for each seed and browser session. Prior ratings motivated the feature hypothesis but did not fit the frozen weights.

Language is not evaluated. Jamendo has no trustworthy track-language field. Spotify lyrics-language filtering remains a separate, unchanged production layer.

This study cannot promote a model and does not change production recommendations. Method identities are absent from public files, browser state, and submissions. Attribution remains hidden until a list score and all five result scores are complete.
